Homepage options

Four complete alternative homepages, plus the current reference build. Every one uses the approved copy from the Homepage section of the Website Refresh Roadmap, the brand palette, and the same header, navigation and footer. What changes is the composition.

This page is a review tool. It is never part of the hand-off.

  • Option A

    Front Porch

    An interlocking mosaic. The hero portrait carries an inset photograph at one corner and the north-star quote at the other; the solutions model is a staggered photo mosaic against a sticky intro; the three foundations climb a diagonal.

    Feels like
    Warm, photographic, family-first
    Signature
    Overlap — nothing sits in a plain band
    Best for
    A parent arriving from social media

  • Option B

    The Index

    A persistent armature. Every section is a sticky rail carrying its place in the funnel against a wide content column. Hairlines instead of card borders, tabular numerals, real negative space.

    Feels like
    Elegant, precise, credible
    Signature
    Foundations is an index — each row cross-fades its own photographic plate
    Best for
    A lawmaker, journalist or donor checking credibility

  • Option C

    The Atlas

    Horizontal motion inside a vertical page. The solutions model and the stories run as scroll-snapped rails; the three foundations are full-height photographic panels that expand under the pointer or the keyboard.

    Feels like
    Confident, modern, hands-on
    Signature
    Panels that open as you move across them
    Best for
    A visitor who came to look around rather than to read

  • Option D

    The Throughline

    The page as a route. An orange line threads the five steps of the solutions model, and the three foundations are full-height photographic slabs that stick and slide over one another as you scroll.

    Feels like
    Cinematic, bold, single-minded
    Signature
    The sticky foundation stack
    Best for
    Making one big impression on a large screen

  • For reference

    The current build

    The homepage built from the original wireframe, with the preview toggles removed. Kept here so the four options above can be compared against what already exists.

The same in all five

  • Every headline, subhead, section intro, solution promise and Join Us block is the approved copy from the roadmap, used verbatim.
  • The roadmap's funnel order is the page order: Hero, How Change Happens, Three Foundations, Mississippi Stories, Latest Insights, Join Us.
  • Empower Blue, Empower Orange and the brand type. Gotham and Whitney are stood in for by Figtree and Source Sans 3 until the licences arrive.
  • One header with five mega menus, one footer, one mobile menu.
  • Exactly one orange filled button per page, per the brand's one-action-per-view rule.
  • WCAG 2.2 AA, reduced motion honoured, working without JavaScript, no sideways scroll at 320px.
