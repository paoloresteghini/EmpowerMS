Brand honeycomb

The tile that ships is patterns/hex-lattice.svg, applied to the Join Us slab in css/homepage.css. This page exists to show two things a static comp cannot: that it repeats without a seam at any size, and that a single file produces every colourway.

Supplied — assets/pattern-blue.png

767×885 raster, tiled at 340px, colour baked into the pixels. It is a composition rather than a tile: roughly half the canvas is empty, so at every repeat the empty region meets the dense one. The seam is visible below, about a third of the way across.

repeat at 340px

Honeycomb — one file, every colourway

Painted with mask-image and a background colour, so navy, orange and tint all come from the same 950-byte SVG. The supplied approach needs one raster per colour, which is why pattern-orange.png exists as a separate file.

Scale

Vector, so the same tile is texture at 60px and architecture at 300px. The raster is fixed at its own resolution and softens as it scales.

What is not in it

The supplied pattern alternates the hexagon with an EM monogram badge. That cell is deliberately absent here: the only logo files in this repo are PNGs rendered from a PDF, and redrawing a logotype by eye from a raster produces a facsimile, not the mark. Add the cell once Empower supplies the vector original — the tile is generated from a script, so it is a re-run, not a redraw.
