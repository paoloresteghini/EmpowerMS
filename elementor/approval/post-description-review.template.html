Every blog post describes itself twice as long as Google will show

All 490 published posts carry a search description nobody wrote. All in One SEO builds each one at the moment the page is requested, from the opening of the article, and cuts it wherever the character budget runs out. They run 291 to 374 characters. Google shows about 160. Everything past that line is written, served, and never read.
